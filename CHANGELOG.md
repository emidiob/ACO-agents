## 0.4.0 — 2026-09-19

- Added seven office entry points: Finance, Commercial, People & HR, Delivery, Administration, Production & Post and Publishing & Media.
- Added 103 canonical roles (96 specialists including two Product integration roles, plus seven office leads); 349 total. Existing 246 role keys retained.
- Reused existing producers, commercial strategists, project managers, publisher/editor roles and software engineers instead of duplicating them.
- Applied early-clarification/concise-action policy to all role methods and entry points.
- Added provider-aware email/WhatsApp/SMS/call/calendar/publication protocol with copy-ready fallback, exact scoped approval, and uncertain-outcome reconciliation. No messaging or telephony service bundled.
- Added 24 task playbooks, eight blank project templates, production/publishing manuals and beginner upgrade guide.
- Added offline intake, action-plan, Decimal budget and ComfyUI static-preflight helpers; no external action execution in these helpers.
- Made office/skill counts configuration-driven and updated generation, installation and validation.
- Private registry schema remains 1. No change to real accounts, cloud permissions, Drive contents or employment/payment decision authority.

## 0.3.0 — 2026-09-19

- Replaced plugin packaging with a plain skill-library architecture.
- Retained 246 generic roles; expanded 113 previously thin technical/legal/recruitment procedures.
- One canonical Markdown role definition per key; generated namespaced TOMLs/catalogue and explicit cross-office dependencies.
- Nine namespaced native skills and a generated minimal local record/event runtime.
- Added multi-organization/activity/client/brand/project scope rules and task-local sessions.
- Added repeatable local bootstrap, immutable checkpoint events, context proposals, revision/hash conflicts and pending/saved distinctions.
- Added collision-safe managed installation, backups, rollback/recovery and targeted uninstall.
- Added reviewed Git migration with legacy fingerprints, backup/work branches and preservation of unrelated/private files.
- Added optional explicitly authorized immutable Drive event transport; no bundled connection or background sync.
- Added beginner manual, Italian quickstart, ChatGPT project instructions, migration prompt, security limits and tests.

This release does not claim a live end-to-end validation of every ChatGPT/Codex/VS Code environment or Google account. See docs/VALIDATION.md.
