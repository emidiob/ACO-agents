# Human acceptance cards — not run by the unit suite

Use the same source material, model, budget and tools for a baseline/new-method comparison. Hide the version label from reviewers where practical. Never manufacture scores or present synthetic method compliance as improved outcomes. Record failed and unavailable checks.

| Task | Representative input | What a reviewer should look for |
|---|---|---|
| Artist development | Three actual works, current questions and weekly capacity | Close observations, useful counter-readings, protected making time, no fabricated facts or opportunity-first repositioning |
| Blind critique | Actual work without biography/artist context in a clean session | Interpretation grounded in visible material, uncertainty, competing readings, no reconstruction of withheld context |
| Curatorial proposition | Documented works, audience and real venue constraints | Meaningful work relationships, temporal/spatial logic, availability/rights uncertainty and producer-ready questions |
| Gallery approach | Real programme and relationship history | Specific affinity and reason to contact, truthful relationship claims, concise voice, no unauthorized send |
| Brand strategy | Real customer evidence plus untested hypotheses | Evidence/assumption/approval distinction, alternatives and tradeoffs, no invented validation |
| Brand identity + website | Approved system and real content | Recognizable applications, readable typography, real rendered inspection, accessible interactions, no imposed template aesthetic |
| Social cycle | Chosen actual accounts, assets, rights and analytics | Feasible production cadence, channel-specific treatment, evidence limits, approved packet binding and honest publication state |
| Film/postproduction | Actual clips and deliverable requirements | Continuity, rhythm, sound/color/timebase awareness, inspected outputs, no command-success-as-artistic-approval claim |

Suggested ratings are qualitative: useful / needs revision / unsupported. Record specific evidence and what would improve. Do not rate people, protected characteristics, artist market value or admission likelihood.

These cards are **not executed** in the release tests. The package verifies local software/contracts; an actual user and appropriate reviewers must assess creative outputs in the real environment.
