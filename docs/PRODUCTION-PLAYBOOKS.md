# Production company playbooks

## Film/commercial: concept to master
Ask early for approved creative brief, deliverables, budget/date, source material, rights and owner. Route strategy/creative through Agency where needed, and production through existing executive/integrated/film producers plus line production.

Plan: treatment and coverage -> crew/camera/set/styling -> location/casting/permits -> ingest/backup -> offline edit -> locked picture -> conform/VFX -> grade -> audio -> captions/versions -> QC -> approval -> archive. The order can overlap with explicit dependencies; do not treat it as a compulsory waterfall.

Deliverables: scope/cost plan, shoot schedule, media manifest, cut/version list, review notes, color/audio specifications, rights/credit ledger, master variants and acceptance checklist. Ask before booking people, purchasing equipment, installing tools or launching material paid renders.

## Postproduction job
First resolve media availability, cut/version, target length/ratios, frame rate, source encoding, output color target, audio/caption requirements, deadline and what the editor is allowed to change. A single correction should not trigger a new creative strategy.

Use video editor/assistant, conform editor, compositor, colorist, sound/dialogue/mix, localization and delivery QC only as needed. A plan may use these methods without all those subagents running. Keep original files and reversible project files. Check picture/audio/caption version alignment.

## Retouching/photo production
Resolve the actual originals, approved references, alterations allowed/forbidden and output use. Use general, beauty/fashion or product-specific retouch. Preserve identity/product geometry, garment texture, required labels and rights. Deliver editable layers/masks when tools support them; otherwise provide a precise intervention brief. A before/after comparison should state what changed rather than hide substantial transformations.

## CG/VFX
Start from verified asset/plate dimensions, color pipeline, renderer and budget. Prototype a representative shot before final frames. Maintain topology/UV/material/pass specifications, alpha convention and transform/version manifest. No assumption that a DCC project has rendered successfully. Qualified humans handle real-world rigging/structural/electrical safety.

## ComfyUI / generative media
Read [the ComfyUI protocol](../skills/aco-office-concierge/references/protocols/COMFYUI.md). Use actual workflow/API exports and verified object_info/model inventory. Distinguish graph authored, static checks passed, queued, executed and output reviewed. Unknown custom nodes require review and install approval. Keep a small reproducible pilot and evaluation rubric before scaling.

## Sound and localization
Plan cue sheets, source rights, recording/voice consent, dialogue cleanup, mix/stems, captions and local-language review. Measure against the actual delivery specification; no universal loudness target. Never fabricate words from inaudible recordings or claim a human native-language review that did not occur.

## Capability boundary
These are roles and workflows, not bundled cameras, paid crews, Photoshop/Resolve licenses, render farms or model weights. Execution requires actual authorized tooling; otherwise outputs are labeled plans/scripts/briefs. See [tool integration rules](INTEGRATIONS.md).
