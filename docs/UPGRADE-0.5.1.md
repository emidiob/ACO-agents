# Upgrade to ACO v0.5.1

This full release uses the latest 363-role v0.5.0 specialist-upgrade package as its baseline, not the earlier alternative 361-role v0.5.0 ZIP. It preserves all 363 roles and 16 entry-point skills. Six office recipes bring the workflow total to 38. A 40-entry optional resource registry captures both screenshot batches. Three ambiguous identities remain gated; all source/asset/runtime claims are dated, conditional and not execution-tested.

The breaking behavioral change is intentional: compact storage is the default. One index plus canonical ACO.md documents replaces per-session/event/project-proposal clutter. Small active clients/brands/activities can remain sections; proposals/leads/applications remain pipeline rows. Requested deliverables still exist. The previous backend remains only through explicit --legacy-memory. No automatic migration or deletion of existing Drive content occurs.

## Repository first, installation second, private cleanup separately
1. Extract the new ZIP outside your existing Git checkout.
2. In Codex follow the README’s “Updating GitHub and local installs” instructions FROM THE NEW PACKAGE. Preview, backup, apply, test, review and normal push. Do not change Drive.
3. Update local skills/profiles using the new source installer and start a fresh host session. Copy new ChatGPT project instructions or explicitly reread CHATGPT.md at the updated ref. Merely uploading GitHub does not replace old in-memory or installed instructions.
4. Verify no proposal creates a folder. Existing legacy knowledge is intentionally refused by the default local initializer; use reviewed consolidation rather than creating another hierarchy.
5. Ask separately for an inventory and cleanup plan for existing Drive notes. Approve exact merges/moves only after preserving useful original documents and access boundaries.

No upstream tools, fonts, assets, models, cookies, subscriptions, APIs or schedules are installed. Resource registry inclusion is not license clearance or a working connector. The ACO LICENSE is unchanged.
