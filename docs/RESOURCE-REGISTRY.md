# Optional Tool & Skill Registry

Version 0.6.2 preserves the 62 supplied-resource entries and adds 35 curated sources/tools, for **97 entries** and **61 task workflows** across ACO. The registry is intentionally optional: most tasks should use zero or only a few external resources. Three names are unresolved; partial source reviews remain explicitly marked. Nothing here is automatically installed, connected, approved or bundled.

Use the [small resource index](../skills/aco-office-concierge/references/resources/INDEX.md), then the relevant category card or one CLI result. Do not load the whole registry into every chat. The single canonical machine source is `skills/aco-office-concierge/references/resources/REGISTRY.json`; category cards and role mappings are generated from it.

All 363 roles and 16 skills inherit the compact-storage and optional-tool gates. No new personas were needed.

Taste, Impeccable, UI UX Pro Max and Design Motion Principles inform original design/motion methods; I Have ADHD and No AI Slop inform optional action-first and editorial-review methods; OpenSEO/Crawl4AI/Browser Use/Maxun/Dify/Langflow/OpenHands and the other apps remain external capabilities. Their upstream text and software are not copied into the package. Asset galleries and libraries remain optional resources, not cognitive rules. LibreChat/Shepherd/VTuber are not suddenly installed agent processes. The screenshot’s schedules remain inert recipes until a real scheduler is authorized.

## Pick, do not hoard
```bash
python3 scripts/aco_cli.py resource-search --query "scroll motion" --role creative_frontend_engineer
python3 scripts/aco_cli.py resource-search --role comfyui_workflow_engineer
python3 scripts/aco_cli.py resource-search --query "Shepherd" --include-unresolved
python3 scripts/aco_cli.py resource-plan --request examples/resources/consult-taste.json
```

Search is transparent lexical/role navigation, not an autonomous intelligent ranking or security approval. Default shortlist is at most three; no relevant candidates means no forced tool. Resource plans never execute. Installation/use plans require fresh host capability evidence, exact scope, applicable authorization, current license review, cost/voice/private-transfer checks as relevant. The host must enforce real permissions; a caller writing an approval string is not proof of authorization.

## Execution boundaries
Use existing connected providers first. A reference list is not a capability inventory. Email/WhatsApp/SMS/calls, browser execution, local GPU rendering, asset purchases and deployment need the actual matching tool. Reconcile uncertain outcomes before retrying. No broad account cookies, secrets, permission changes or security bypasses.

Hosted GitDiagram/Gitingest/DeepWiki/GitMCP routes require data-boundary review; public visibility is not blanket permission to transfer proprietary content. Existing authorized repository reads and scoped local inspection usually suffice. Code-generated documentation is checked against the actual commit and test evidence.

Current licensing applies per source, component, model and asset. ACO’s license covers ACO, not third-party resources. This release contains no third-party source packs, models, fonts, paid assets or copied skill bundles. Review dates reflect source inspection, not execution, legal clearance, security audit or perpetual compatibility.
