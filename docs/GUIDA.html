01

A better way to work with an assistant

ACO is a library of instructions, not another app to learn. It helps an assistant choose a useful process and show you what happened.

Plate A / The four movesRead from input to verification →
Bring a real task

A draft, a project, a question, or a goal. You can start before everything is perfectly defined.

Use the relevant method

The assistant reads the ACO instructions it can access and applies the ones that fit your task.

See the result clearly

It should tell you what it made and how you can review it.

Know what was checked

Ask what is complete, what remains uncertain, and what needs your decision.

ACO does not connect your accounts by itself. Email, Drive, WhatsApp, and other services work only when the needed tools and permissions are available in your session.
02

Choose where you work

Choose a chat assistant or a local coding assistant. The steps and example message change to match.

Mode / 01—0201 / Chat selected
  1. Give the assistant access to ACO

    Use an authorized repository connection or provide the relevant files. A chat cannot read files it has not been given.

  2. Set up a project if useful

    In ChatGPT, you can copy these project instructions. In Claude, provide the relevant ACO files or repository access. An ordinary chat is also fine.

  3. Ask for one concrete result

    Copy the message beside these steps, replace the brackets, and add your material.

Quick check

Ask which ACO version and files the assistant actually read. Typing “use ACO” does not install or connect anything.

A message you can use
Use ACO to help me with [my task]. Read the ACO instructions you can actually access. Tell me briefly what you need, then make a useful first result. Explain what you checked and what is still open.

  1. Open the ACO folder

    Clone the repository or extract the full release into a new folder. Check that VERSION says 1.0.9.

  2. Check that your tool finds ACO

    In Codex, use $aco after installing the skills. In Claude Code, use /aco when the skill is discovered. See the upgrade guide and command guide.

  3. Work in your own project

    Open the folder for your actual task. Ask the assistant to use only the ACO instructions it needs.

You do not need every tool

Python 3.11+ is needed for local ACO tools. The commands doctor, validate and install help you check and install; install previews changes unless you add --apply.

A message you can use
Use ACO 1.0.9 for [my task] in this project. Check which version and skills are available, read only the relevant instructions, and make a concrete result. Tell me what you changed and which checks you ran.

04

Common questions

Short answers to questions that often slow people down.

Plate C / Reference notesOpen a question to inspect ↘
Do I need to learn every agent and command?

No. Describe the task in your own words. The assistant should choose the relevant instructions. Short commands work only when your environment recognizes them.

Does ACO remember everything I say?

No, not automatically. Saving information requires an available destination and an actual write action. Ask where something was saved if continuity matters.

Can it send email or publish for me?

Only when the right connected tool, permissions, and authorization exist in that session. A draft is not a sent message; a plan is not a published page.

What should I check if it does not work?

Ask which ACO files the assistant can read. In Codex, also check VERSION and the installation status. A GitHub permission error is separate from installing ACO.

Do I need Drive or lots of folders?

No. Start without permanent memory. If continuity becomes useful, choose an authorized private place and save only the decisions that matter.
