# Known limitations — 0.6.2

- This is a role/method library and local utilities, not an always-on service, fine-tuned model, professional staff or access-control product.
- 363 role definitions are preserved, but only 114 received the new curated method links. Full human outcome benchmarking across all roles has not been performed.
- Local unit/integration tests do not demonstrate better artworks, writing, brand strategy, sales or employment outcomes. Never invent validation results for these.
- Source review covers selected publisher pages, catalogues and repository overviews, not exhaustive security, copyright or dependency auditing. Earlier entries are inherited with explicit provenance.
- Some source services/courses may be unavailable, paid, geographically restricted or changed. Recheck at use time. No service or upstream software is bundled or installed.
- Spectrum is reference-only in ACO. Do not reproduce protected standard text or commercial derivatives without relevant permissions or claim compliance/certification.
- A PATH result is not a successful command run; a connected-app name is not an available write action; a user-supplied evidence string is not authenticated evidence.
- Offline readiness checks report structure/arithmetic/approval mismatches. They neither verify sources nor authorize publication, issue legal/tax opinions, score people or judge artistic merit.
- No authenticated Drive/social/email/WhatsApp/phone actions, real scheduler setup, paid rendering, ComfyUI GPU processing or desktop-DCC operation is established by the package test suite.
- Local cleanup uses snapshots and reviewed plans. Live Drive mutation requires available connector actions, an inspected scope and read-back verification. A local mirror is not synchronization.
- Context separation is a behavioral design, not encryption or account isolation. Use real file/app permissions, separate sessions and minimum disclosure. A blind prompt cannot erase context already given.
- Future changes to generated files require regenerate → manifest → validation → tests. User modifications or nonstandard old releases can make migration stop safely; do not bypass it with deletion.
- Shell helpers target macOS/Linux with Python 3.11+. A real host/version must verify native skill/agent discovery. Windows users need an appropriately configured environment; it is not tested as a native Windows installer.

- Behavioral eval files define comparison cases and constraints; `eval-lint` validates their structure but does not run models or prove improved behavior. Human review remains required for artistic, curatorial, brand, writing and visual-quality judgments.
- `context-budget` uses rough static estimates and package sizes. It is not provider token telemetry, latency measurement or proof of the active context window.

- The deterministic router is advisory and benchmark-limited. A 98.57/100 holdout score does not imply universal routing accuracy; unusual, multilingual or underspecified requests may still need Concierge clarification.
- `routing-examples.json` is generic package training/evidence data for the local deterministic router, not user memory and not model fine-tuning.
- The 97.83/100 behavioral simulation is same-model structured review. It is useful regression evidence but is not an independent benchmark or proof of professional quality.
- `capability-resolve` evaluates a supplied inventory only. It does not authenticate an account, discover hidden permissions or execute a capability.
- `handoff-check` validates structure/evidence presence, not whether the evidence itself is truthful.
