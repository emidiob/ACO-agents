# Privacy Policy — ACO — Art & Commerce Office

Last updated: 2026-09-19

ACO — Art & Commerce Office is distributed as an open-source, skills-only agent plugin. The public ACO package does not operate its own remote server and does not collect, store, sell, or transmit user data to the ACO maintainer.

ACO may instruct ChatGPT or Codex to use apps the user has separately connected, such as Google Drive, when that is relevant to a workflow. Access to those services is governed by the user's authorization, the provider's permissions, the ChatGPT/Codex app controls available to the user, and the applicable OpenAI and provider policies.

ACO is designed to use the minimum relevant private context. Users should avoid storing passwords, access tokens, private keys, or unnecessary sensitive personal data in ACO context files.

The ACO maintainer does not receive the contents of conversations, connected Google Drive files, local project files, or private context merely because a user installs the public ACO plugin.

For questions about this policy, use the repository issue tracker: https://github.com/emidiob/ACO-agents/issues
