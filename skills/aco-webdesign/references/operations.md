# Native ACO operations

These arguments select original agent methods. They are not additional host slash commands or a replacement for upstream runtime engines. Invoke `$aco-webdesign polish <target>` in Codex or `/aco-webdesign polish <target>` in Claude. Read only the selected method.

- `document` — [Document the existing design](operations/document.md)
- `extract` — [Extract reusable elements](operations/extract.md)
- `shape` — [Plan the interface](operations/shape.md)
- `craft` — [Build and iterate](operations/craft.md)
- `critique` — [Review design judgment](operations/critique.md)
