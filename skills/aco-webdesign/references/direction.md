# Direction from the actual brief

Identify who visits, what they need to understand or do, the real subject matter, content volume and existing identity. Inspect supplied references visually; record the specific properties to borrow (density, composition, type relationship, image treatment), not an instruction to clone somebody's whole page. If a URL cannot be inspected, disclose that limitation. Preserve user-provided text and assets; label fictional sample data and never invent customer quotes, logos, metrics or endorsements.

For substantial new work make a concrete visual hypothesis: what should command attention, how the composition supports the content, how type communicates the subject and where imagery carries information. Compare a small number of genuinely different options when useful; select a reasonable one when the brief already decides. Explain tradeoffs in a few sentences. Do not force the user to pick from arbitrary styles.

Use `scripts/directions.py` to search six original recipes. Search results are keyword matches, not a trained recommendation engine. They provide starting constraints, content needs and failure risks. Mix only compatible principles and adapt them to the actual brand. A type-led publication, a catalog and an operational workspace should not receive the same hero and three cards.

Respect reference hierarchy: approved brand overrides exploratory inspiration; real product needs override a fashionable treatment. Decide what the first viewport communicates, what changes on narrow screens and which interaction proves the concept. Prototype the difficult representative section early. Revisit the direction only when observed failures or user feedback warrant it.
