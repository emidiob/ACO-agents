The shipped Markdown, recipe data, helpers and examples are independently authored ACO implementations of these general workflow capabilities. No upstream skill text, gallery images, database, detector source or component implementation is bundled. Preserve each upstream project's terms if later incorporating actual source. UI UX Pro Max, Taste Skill, Emil and shadcn advertise MIT; Impeccable is Apache-2.0; Anthropic/Vercel metadata does not establish one blanket license for every bundled skill. React Bits' reviewed LICENSE.md contains MIT plus Commons Clause restrictions. Consult exact source terms for concrete reuse.

This release is a focused first implementation, not a clone of every feature in these repositories. The recipe search is deterministic keyword matching; the HTML checker covers only its listed static checks. The agent still needs judgment, available browser tools and real project dependencies to deliver arbitrary websites. Research popularity does not prove ACO output quality. Packaging/install tests do not prove fresh host discovery or browser accessibility.
