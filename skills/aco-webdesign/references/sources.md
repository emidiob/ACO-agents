# Dependencies and attribution

ACO Webdesign provides native methods, local Python helpers and optional external design data. Python 3 is required for helpers. Rendered inspection requires an available authorized browser tool.

The optional dataset is from [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). Its pinned revision and file hashes are in `../assets/external-data-source.json`. The downloader retains LICENSE and provenance files. Dataset metadata does not grant rights to font binaries, images or other linked assets.

Component and motion libraries are selected for the target project; see [libraries](libraries.md). Preserve their applicable licenses and notices when incorporating source or assets. ACO does not bundle third-party component catalogs or browser extensions.
