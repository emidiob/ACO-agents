# Generate scoped variants

Create meaningfully different variants of the named component using a shared props/data contract. Expose a project-local switcher when useful. Verify every variant with identical content, keyboard behavior and responsive constraints before selecting one.

Completion evidence: Working variants and a comparison; variant creation does not claim an automatic browser-to-source engine.

Use the project’s existing conventions and available tools. Report missing capabilities explicitly; a written procedure is not runtime proof.
