# Build and iterate

Establish the product task, choose a visual direction from relevant evidence, build a representative working slice, inspect its rendering, then complete the requested routes and states. Fix observed problems and repeat affected checks.

Completion evidence: Editable implementation, working primary flow, rendered narrow/medium/wide inspection and explicit unresolved production connections.

Use the project’s existing conventions and available tools. Report missing capabilities explicitly; a written procedure is not runtime proof.
