# Review technical behavior

Use static checks for source-level issues, then inspect rendered semantics, focus, keyboard flows, responsiveness and runtime errors. Measure performance with available profiling tools. Keep heuristic style findings separate from functional failures.

Completion evidence: Each finding has location, reproduction, impact and verified or untested status; no certification from an empty report.

Use the project’s existing conventions and available tools. Report missing capabilities explicitly; a written procedure is not runtime proof.
