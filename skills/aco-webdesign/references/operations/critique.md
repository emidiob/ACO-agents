# Review design judgment

Inspect the actual rendered surface and identify what competes with the main task. Assess hierarchy, navigation, content, imagery and distinctiveness against the brief. Separate observations from preferences. Prioritize three concrete changes with location and expected effect.

Completion evidence: An evidence-linked critique; code changes only when the request includes remediation.

Use the project’s existing conventions and available tools. Report missing capabilities explicitly; a written procedure is not runtime proof.
