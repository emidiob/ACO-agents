# Select real libraries

Inspect the project stack and existing dependencies, then compare maintained official APIs and required capabilities. Reuse installed foundations. For additions preserve upstream license and lockfile provenance, integrate real components and test their composition.

Completion evidence: Actual compatible integration with verification, or a clearly identified selection-only result.

Use the project’s existing conventions and available tools. Report missing capabilities explicitly; a written procedure is not runtime proof.

For ACO-native sources, search and export the component/effect catalogs using [interactive tools](../interactive-tools.md). Keep each record’s behavior and format limits explicit.
