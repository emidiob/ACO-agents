# Motion resources

Optional catalogue, not an installation list. Consult current source and actual host capabilities.

## design-motion-principles

**Design Motion Principles** · skill · source_reviewed · reviewed 2026-09-20

Source: https://github.com/kylezantos/design-motion-principles

**Use:** Create/audit motion based on purpose, frequency, state change and cost.

**Avoid:** Do not imitate named designers as universal styles, add motion to everything, or override reduced-motion preferences.

**Checks:** Original ACO motion decision method; source methodology reviewed, not copied.

Roles: `interaction_designer`, `motion_design_director`, `creative_frontend_engineer`.

Required capabilities when executing: none declared; inspect the actual task/tool.

[Original ACO method](../playbooks/MOTION-INTEGRATION.md). External upstream content is not bundled. No execution tests performed.
