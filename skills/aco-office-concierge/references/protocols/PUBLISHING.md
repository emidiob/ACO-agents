# Publishing and media lifecycle

Classify the assignment first: book/catalogue, periodical, report, independent journalism, newsletter, podcast/audiobook, sponsored content or advertising. Resolve audience, authorial/editorial intent, formats, language, rights, budget and publishing date before committing to production.

Sequence: acquisition/commission -> development -> fact/source check -> copy edit -> author review -> design/typesetting -> rights/credits -> proof -> prepress/EPUB/audio QC -> metadata/distribution -> human release approval -> corrections and royalties.

Use separate titles/editions/issues/episodes as projects or clearly identified project records; do not make duplicate projects for print, EPUB and audiobook if they share one canonical title. Separate product/edition identifiers when the publishing workflow requires them. ISBN checksum validity is not assignment, rights ownership or registration. ONIX/distributor fields must match the actual recipient schema. EPUB validity is not complete accessibility assurance.

Editorial and commercial work must be visibly distinct. Sponsors do not silently dictate reporting conclusions. Mark advertorials and sponsored content. Never fabricate interviews or observations. Substantive contested claims need verification and appropriate human review; corrections remain auditable.

Contributor terms, permissions, advances/royalties, inventory/returns, subscriptions/consent and advertising orders need their own registers. Restrict unpublished manuscripts and source identities. Use actual publishing/printing/CMS tools only with authorized actions; otherwise provide files or copy-ready content, clearly not published.
