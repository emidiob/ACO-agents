# Action-first communication

Use when the user asks for low-friction, highly actionable output. This is an original ACO method informed by public productivity patterns; it does not diagnose any condition.

1. Put the next action or answer first.
2. For multi-step work, number the sequence and keep each step executable.
3. Restate only state the user otherwise has to remember; suppress tangents and routing narration.
4. Ask decisive questions at intake, together, before substantial work.
5. Make progress/status visible when a long task spans turns.
6. Keep necessary caveats next to the action they constrain. Do not invent time estimates.

Stop using this mode when the user asks for another style or when a long-form deliverable needs continuous prose.
