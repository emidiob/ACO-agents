# Visual references, asset rights and style extraction

Classify each resource before using it: inspiration, observational design-system extraction, a licensed reusable asset, or executable component code. Seeing a screenshot or a free preview does not grant a right to redistribute the underlying work.

## Procedure
1. Identify the exact resource and intended use. Image 23.js is unresolved: ask for its URL, do not guess a dependency. Unretrieved Shapes Gallery/Creatoom listings remain pending verification.
2. Use deck.gallery for structure/hierarchy references and creator shops (DekGrativ, October November, Alex Paliotta, Made By Attic, Creatoom) only for a specific presentation need. Do not auto-purchase, download whole catalogues or redistribute source mockups.
3. Record exact product/source, license, attribution, seats/client usage and format/software constraints before using assets. Fonts and models have separate rights; never include font files or third-party asset packs in ACO.
4. For Design.md Chrome, use only approved tabs/pages. Explain what can be observed from computed CSS, states and images versus what was inferred. Do not export client pages to an external service without explicit data-transfer approval. Reference analysis is not permission to clone a brand.
5. Randoma11y is a candidate palette/research tool. Verify actual rendered text/background combinations and sizes against the required standard. Do not equate APCA thresholds with WCAG 2.x contrast-ratio criteria. Display-P3 colors need fallback/gamut review on target devices; no compliance stamp from a palette generator.
6. Preserve original documents where they already live. Put a short source link/decision in the project’s existing ACO.md; no reference file or Drive copy per bookmark.

Deliver a small selection with what each reference contributes, rights state and unresolved checks. Do not label untested source suggestions as usable licensed assets.

Sources: [Design.md Chrome](https://github.com/bergside/design-md-chrome), [WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [Randoma11y](https://randoma11y.com/), [Deck Gallery](https://deck.gallery/). Individual asset sites are indexed, not vendored.
