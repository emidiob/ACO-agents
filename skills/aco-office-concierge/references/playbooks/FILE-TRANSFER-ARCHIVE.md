# File transfer and media acquisition

Use for authorized local transfer, public-media acquisition and archival intake.

1. Confirm ownership/permission and source terms before downloading or moving media.
2. Preserve source URL, capture date, caption/metadata and rights notes when the material enters an archive.
3. Verify destination device/folder and checksums for important masters; transfer is not backup.
4. Do not bypass authentication, paywalls, DRM or access controls.
5. Separate working references from publishable/licensed assets.
6. Keep the archive index compact; do not create a memory file for every downloaded asset.
