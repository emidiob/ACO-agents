# Selective design methods, not mandatory style

## Intake
Determine task, audience, real content, visual authority, deliverables and what is already approved. Read existing brand/design facts first. Ask at most three essential missing questions, not a questionnaire. A blind exploration must not fetch personal/project history first.

## Method
1. Decide whether the job is discovery, a fresh direction, design-to-code or refinement. A reference catalogue alone is not a design direction.
2. Pick at most a few relevant references. Compare hierarchy, type scale, alignment, density, rhythm, image roles, state behavior and what the material communicates. Explain the transferable principle instead of copying a whole identity.
3. Define a small testable design contract from actual content: representative view, long copy, empty/error/loading, narrow screen, keyboard focus and reduced motion. Preserve approved constraints.
4. Build one meaningful slice before a full system. Inspect a real render with the correct viewport/content. An unavailable browser means untested—not beautiful by assertion.
5. Critique the work against its stated purpose. Prioritize the largest defects, then refine spacing, type and interaction. Use snapshots/evidence to compare revisions; never claim visual QA from reading code only.
6. Stop when the deliverable criteria are met. Do not endlessly redesign to match a tool’s aesthetic.

Taste, Impeccable and UI UX Pro Max offer different ways to structure exploration and revision. Their role here is optional evidence/method inspiration, not universal aesthetic rules. No blanket prohibition on black, centering, gradients, cards, particular fonts or genres. No automatic Next.js/Tailwind migration. Awesome Claude Design and Agency Agents are catalogues to consult selectively, not role packs to install wholesale.

## Result
Deliver the design/code and brief verification, not internal discussion between ten directors. Ask early if the actual target/art direction is unknown. Keep private references in the existing project ACO.md, not one file per inspiration.
