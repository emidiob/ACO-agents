# Capability-first tools and office integrations

Original ACO operational method · v0.6.0. Select for the relevant task; do not load every playbook.

## Separate four facts
A catalogue entry means a resource is known. A command found on PATH means a local file can be located. A connected integration exposes particular actions. A successful action receipt establishes only the state that the provider actually returned. Never collapse these facts into 'available and working'.

## Selection sequence
Use a built-in/connected capability that already fits. Otherwise inspect the relevant registry card, its source-review date, data destination, terms, maintenance burden and the missing task benefit. Select at most a few candidates. Do not install a new CRM to record three leads or choose a runtime merely because it has many stars.

Run the local capability audit only as an environment inventory. It does not execute detected binaries, inspect credentials, connect accounts or authenticate services. For remote tools, discover current schemas in the host and perform the necessary authorized read before relying on connected data. Do not guess tool names, HTTP routes, account identifiers or permissions. Generic permission flags in a profile do not prove a write action is permitted.

## Office options
Twenty, Plane and n8n are optional operational systems when scale and a maintenance owner justify them. Listmonk/Postiz may support publishing when exact account/platform operations exist. ACO does not bundle or automatically run these services. Keep one system authoritative for each record. If an external calendar or CRM is authoritative, store its relevant link and concise state, not a full duplicate in Drive.

## Authorization and recovery
Install/deploy needs exact source/version, dependency and network review, approved destination, costs and rollback. Sending email/WhatsApp/SMS, calling, scheduling, publication, spend, sharing or deletion needs the actual appropriate action plus authorization. Reading call history does not place calls; generating speech is not telephony. An existing denial is not permission to try a different channel or connector.

Bind approval to the recipient/account/content/timing. On a timeout, reconcile before retrying. Report prepared, accepted, sent, published, delivered, failed or unknown according to evidence. If missing, return a copy-ready draft with the status outside the copy. Never claim always-on operation without an actual scheduled service and a verified schedule.

## Retention
No tool bookmark produces a new Drive file. Keep private receipts only as needed for audit, reconciliation and the user's retention policy. Do not copy secrets, personal profiles or private connector IDs into the public package.
