# Optional production resources: local rendering, composition and voice

## Route by actual job
Generation, deterministic composition, editing/conform, voice synthesis/transcription and outbound telephone calls are different capabilities. Determine deliverable, rights, model/host, hardware/budget, source assets and intended data destinations before execution. Ask only the blocking questions early.

HyperFrames and Remotion are optional programmatic composition routes; pick the one that fits the existing project rather than adding both. Voicebox and Open-LLM-VTuber may serve audio or interactive avatar work; neither proves telephone access. Verify voice/likeness consent, model/avatar licenses and the chosen local/cloud route. Open Higgsfield AI has multiple candidate repos: obtain the exact owner before deployment, cost or privacy claims.

## ComfyUI Continuity procedure
1. Read the actual installed repository/ref and ComfyUI version; inspect available node IDs, models, GPU/VRAM and dependencies. No automatic installs/downloads or optional NVIDIA weight-extraction setup.
2. Detect the old ComfyUI-MiniMax-Creator name and new Continuity pack before proposing install. Their node IDs can overlap; do not clone a duplicate pack or delete either folder blindly. Preserve user presets/settings and review the exact upgrade plan.
3. Select the model family for the task. The reviewed README lists two video-with-audio families and four still-image families—not six interchangeable sound-video models. Check the current models documentation rather than freezing these capabilities into every prompt.
4. Assign reference roles explicitly: person, location, composition or look. Design the initial/final frame or still pre-stage first when needed; attach only approved actual assets.
5. Specify each shot’s action, framing, incoming/outgoing state and audio continuity. Keep generation settings tied to the chosen family. Map reference handles without fabricating attachments.
6. Review seams and generated clips, not just graphs. The source itself reports cumulative brightness/sharpness drift; inspect real cuts and retain QC failures. Never promise solved identity or perfect multi-shot continuity.
7. Check every network route. Rendering can use local weights, while an optional prompt refiner can send material to the configured external provider. “Local app” is not a blanket no-network guarantee. Cost includes hardware/time as well as any services.
8. Preserve seeds/versions/asset roles and accepted settings in the real production manifest/handoff. Retain actual media deliverables where requested; do not create memory folders for every proposed shot.

Fallback: a truthful workflow/shot/prompt plan with missing prerequisites. Never claim a render, audio file or tested graph without execution. Do not install optional packs or hosted gateways without separate approval.
