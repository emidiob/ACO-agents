# SEO operations

Use live data when the task depends on rankings, demand, backlinks or crawl health.

- Start with objective, target market/language, site scope and baseline.
- Separate technical crawl/indexing issues, content relevance, authority/backlinks and conversion outcomes.
- Record data source/date and distinguish estimates from first-party analytics.
- Verify high-impact recommendations against the actual site and Search Console/analytics when authorized.
- Do not create pages/keywords solely because a tool reports volume; protect editorial value and user intent.
- Track changes and outcomes rather than claiming causality from one ranking movement.
