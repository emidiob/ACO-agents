# Portfolio sequencing and articulation without invention

Original ACO operational method · v0.6.0. Select for the relevant task; do not load every playbook.

## Diagnose the use
Identify the reader and use: studio visit, open call, gallery introduction, exhibition dossier, book or public site. Read the actual submission constraints. Do not write a new identity for every recipient. Separate artist statement (practice), work text (a particular work) and biography/CV (verified facts).

## Select and sequence
Inventory only provided or authorized works. For each candidate, verify title, date, medium, scale/duration, collaboration credits and status. Note whether the image is documentation, a render, a detail or an installation view. Never let a persuasive render masquerade as a completed installation.

Choose a sequence with an opening, development, contrast and ending suited to the reader. Preserve enough detail and scale information for understanding. A short coherent selection can be stronger than all available works. Explain one alternative sequence rather than filling the dossier with repeated images. Use crops for a reason and retain captions that prevent misreading.

## Writing
Start with specific actions, materials and questions before theoretical generalities. Keep intentional ambiguity where it belongs. Avoid retrofitting every work to one concept or using prestigious names as evidence. Quotations need a retrievable source; claims about awards, acquisitions or institutional relationships need confirmation. Do not fabricate collaboration credits, identities or personal histories.

For critical writing, distinguish observed work, interpretation and documented context. For a statement, preserve the artist's voice and allow refusal of a conventional autobiographical narrative. Offer length variants only when useful; do not create separate Drive memory files for each draft.

## Deliverable QA
Check page/image limits, legibility, filenames, credits, links, video permissions and reproducible reading order. Use actual available document tools for layout; do not claim a PDF was produced from a text outline. Review the rendered pages before calling a layout final. Ask for missing source images rather than using unrelated placeholders without disclosure.

## Retention
Keep the current canonical portfolio link, version, purpose and a concise selection rationale in ACO.md. Preserve real masters and commissioned deliverables separately; rejected sequences do not become projects. Do not duplicate bibliography or source contracts into the memory file.
