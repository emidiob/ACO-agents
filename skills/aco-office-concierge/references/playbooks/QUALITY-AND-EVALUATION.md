# Release quality, regression tests and realistic evaluation

Original ACO operational method · v0.6.0. Select for the relevant task; do not load every playbook.

## Define what evidence can prove
A unit test establishes behavior for its fixtures. A source inspection establishes what a source says. A browser test establishes specific exercised states. A human review evaluates an output under a stated rubric. None is a universal professional-quality certificate.

## A bounded test plan
Choose representative tasks from artist development, brand, web, social, office and production. Keep the brief, input materials, model/version, tools and budget the same when comparing methods. Record independent ratings where feasible, with reasons and disagreement. Do not grade an upgraded method only by its own self-report or word count. Mark unrun cases honestly.

## Useful invariants
Check that rejected proposals create no entity files; speculative brand activities remain inline; a claim without evidence is not marked validated; publication has exact scoped approval; unavailable tools yield a draft; blind passes disclose prior-context exposure; changed remote content is not overwritten silently. Tests should include malformed, stale and conflicting inputs, not only happy paths.

## Execution/security tooling
Promptfoo is an optional model-evaluation runner, potentially with billable provider calls. Gitleaks and Semgrep are optional scanning tools; verify versions, scan scope, local-vs-cloud behavior and rule licences. No finding does not prove no secrets or vulnerabilities. Do not run downloaded rule packs, code or scans against unrelated systems without authorization. Keep red-team tasks bounded to authorized assets.

## Release gate
Run generation/parity checks, all unit tests, migration and installation smoke tests, static link/privacy checks and a clean archive extraction. Record the exact commands, version, counts and limitations. Keep the proprietary ACO licence intact and third-party restrictions distinct. Do not remove historical licence notices or pretend already-published permissive rights can be revoked.

## Outcome
Publish one truthful test report and a concise known-limitations section. Do not inflate totals by counting generated roles as executed agents. A final package is a finished distribution for its stated scope, not proof every external integration works. Real host/creative benchmarks remain separate acceptance work.
