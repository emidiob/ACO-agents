# Native ACO motion — coverage and provenance

This is an original ACO implementation of authoring workflows, not a renamed upstream skill distribution. Runtime instructions and all required method modules live in `aco-motion/`. No external agent skill, Motion MCP server or premium account is required to read or execute the local methods. Actual rendering still requires the relevant software, project dependencies and assets.

## Limits

This coverage maps workflow areas, not every upstream example, effect or renderer API. Exact APIs are resolved against current official documentation and installed types. Premium component source, MotionScore methodology, hosted search/editor tools and cloud rendering services are not reproduced or represented as native ACO capabilities. Local instruction/link tests do not demonstrate rendered quality, performance or host behavior. Real projects require the verification described in each method.

The ACO technical registry remains separate: this native method does not silently promote candidate entries or claim a new benchmarked model capability.
