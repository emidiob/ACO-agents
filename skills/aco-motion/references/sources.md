# Dependencies and attribution

ACO Motion contains local methods for video composition, captions, maps, editable timelines, previews, exports and interactive animation. Actual execution requires the relevant project, assets and installed software.

Consult current official documentation for [Remotion](https://www.remotion.dev/docs/), [Motion](https://motion.dev/docs) and [GSAP](https://gsap.com/docs/v3/) when those engines are used. Verify versions and preserve applicable third-party terms. Hosted rendering and paid services require their own access.

Use [dependency setup](dependencies.md) and [verification](review.md) for the target project. A local method or successful static check does not establish rendered quality or runtime performance.
