# Context Setup

Use when the user wants to create, populate, update, review, or restructure the private context that powers the office skills.

Choose the smallest relevant template(s) from `references/`. Keep stable facts separate from current strategy, preferences, hypotheses, and open questions. Do not invent missing facts. Avoid secrets and unnecessary sensitive personal data.

The public plugin ships templates only. Filled private context belongs in a user-controlled private store and should not be committed to a public repository.
