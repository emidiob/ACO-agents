# Project contract

Inspect the selected project and its instructions before writing. Keep source assets intact; use new output paths and check ownership before replacement. Work only within the requested scope. Preserve user edits, licenses and notices. Keep private footage, credentials and client data outside the public skill library. Do not create memory/session files for routine work. Record meaningful delivery evidence with the requested artifact, not as a claim that a remote service was updated.

A local export request includes ordinary local build/render steps; it does not authorize paid services, uploads, publishing or deployment. Use real available tools, report errors and distinguish source creation, successful execution and visual approval. Never invent screenshots, rendered files, listening or independent reviews. These rules apply equally in Claude Code, Codex and their VS Code extensions.
