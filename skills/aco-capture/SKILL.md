# ACO Capture

Use [the photographic method](references/capture.md) for Frame → Moment → Light → Matter and the seven camera approaches. Preserve the user's scene; examples illustrate camera choices and must not become default subjects. Choose one physically coherent approach. Return four short paragraphs and a concise camera sentence when useful.

For supplied images, inspect them and assign each an influence (identity, framing, light or material); keep pose separate from identity. Resolve conflicting references before drafting. The local inventory helper records real files, never fabricated provider tags.

For a series, keep subject and scene invariants explicit while changing the requested photographic treatment. If asked to generate, use the available image tool and inspect the result against the method's acceptance review. If only a prompt is requested, finish with the tailored prompt and supported settings. Never report generated-image quality from prompt inspection alone.
