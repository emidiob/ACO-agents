# Recruitment Office

A candidate-side career and job-search office for strategy, live job discovery, company/recruiter research, CV/portfolio/application materials, networking, interviews, compensation, negotiation and pipeline management.

The operating principle is **career improvement over application volume**.

## One-line invocation

> Use the Recruitment Office.

or

> Use the Career Office.

## Typical context

```text
career-context.md
+ job-search-context.md
+ CV / portfolio / profile files
+ application history
+ current brief
```

Live opportunities should be verified against an original/official source when feasible and dated.
