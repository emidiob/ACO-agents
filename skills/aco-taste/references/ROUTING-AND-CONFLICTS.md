# Cross-skill visual orchestration (ACO original; Frontend Stack studied)

**One owner:** existing ACO specialist remains responsible for output. `aco-taste` supplies direction and a mandatory visual QA gate, not competing implementation instructions. Load one main taste module plus at most two relevant modules per phase. Do not concatenate seven upstream skill prompts into one context.

### Select by medium and task
- Web/portfolio/landing: lead `aco-webdesign` + taste direction, subject-based visual materials, actual browser screenshot review.
- Product UI: `product-office`, existing design system, UI States/accessibility, taste comparison; use animated details sparingly.
- Images/photography: `aco-image` / `aco-capture` plus taste composition, material/light/crop and actual image QA.
- Video/film: `aco-video` / `aco-genjutsu` plus taste sequence, camera, tempo, continuity and contact-sheet QA.
- Animation/motion: `aco-motion` plus taste motion-craft review.
- Brand/editorial/slide/PDF: agency/publishing + taste typography/spatial grid, export proof and visual review.
- Exhibition/spatial/CG: artist/production + taste scale/material/lighting, rendered evidence and installation consistency.

### Conflicts
1. User-approved identity and explicit request override defaults from any source.
2. Legibility, rights, privacy, safety and actual tool capabilities override aesthetics.
3. Product UI prioritizes quick functional feedback; film/marketing motion may use expressive timing.
4. A reused frontend component must preserve the code's behavior. A color heuristic cannot silently rebrand it.
5. A `DESIGN.md` extracted from code is descriptive until approved. Raw references cannot silently rewrite it.
6. Historic examples from Taste, Hallmark, Anthropic, gstack, Emil and UI Skills are research data; a named repo does not imply installation or accepted judgment.
7. If review conflicts with the owner's explicit direction, document the tradeoff and honor the owner within legal/technical constraints.

**Enforcement:** Concierge's [global automatic routing](../../aco-office-concierge/references/protocols/VISUAL-TASTE-ROUTING.md) controls triggering and the medium's existing ACO skill supplies execution. Passing deterministic tests does not prove taste.
