# Product Office

A generic specialist module for **websites, web apps, software products, internal tools, APIs and AI-enabled products**.

The module contains **51 product-office agents**. It can be used on its own or together with the Agency Office and Artist Office.

## Operating model

```text
PRODUCT / DISCOVERY
    ↓
UX / DESIGN
    ↓
ENGINEERING
    ↓
QUALITY
    ↓
INFRASTRUCTURE / RELEASE
```

Support researchers/prototypers can be inserted wherever they reduce risk or accelerate learning.

## One-line invocation

> Use the Product Office.

Then brief the problem naturally. `product_software_orchestrator` chooses context, team, sequence and escalation.

## Context

Typical context stack:

```text
company-context.md
+ client-context.md (when relevant)
+ product-context.md
+ technical-context.md
+ project-context.md
+ current brief
```

For website work that is primarily branding/communication, combine Product Office with Agency Office. For artist websites or software artworks, Artist Office should retain artistic authority while Product Office handles technical realization.
