# ACO Concierge

The canonical routing protocol is [CONCIERGE.md](skills/aco-office-concierge/references/protocols/CONCIERGE.md).

Use ACO, then describe your goal. The concierge resolves the task, minimal team, private scope, capability checks, checkpoints and final verified/pending status. It asks only questions that materially block the job. It does not replace user approval or operate in the background.
